# 🦎 Хамелеоны

Логическая браузерная мини-игра, созданная по мотивам классической математической головоломки о хамелеонах, меняющих цвет при встрече друг с другом. 
Проект вдохновлен видеороликом [на YouTube](https://www.youtube.com/watch?v=p5PjgLijuG8) с разбором её с математической точки зрения.

*Эта хрень никогда не должна была появиться не что-то пошло не так...*
